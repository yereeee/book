# 독서 기록 앱 요구사항 정의서

## 1. 개요

### 1.1 프로젝트 목적
개인이 읽은 도서를 기록하고, 사용자가 직접 정의한 카테고리와 상태로 관리할 수 있는 웹 애플리케이션.

### 1.2 대상 사용자
단일 사용자 (개인 독서 기록용)

### 1.3 핵심 가치
- 도서 정보를 빠르게 검색해서 가져오기 (직접 입력 최소화)
- 내 방식대로 분류하기 (카테고리/상태 자유 정의)
- 인터넷 없이도 사용 가능 (로컬 저장)

---

## 2. 기능 요구사항

### 2.1 도서 추가

#### 2.1.1 Google Books API 검색
- 검색창에 제목 또는 저자명 입력 시 Google Books API로 결과 조회
- 검색 결과 목록에서 원하는 책 선택
- 선택 시 다음 정보 자동 입력:
  - 제목
  - 저자
  - 표지 이미지 URL

#### 2.1.2 수동 입력
- API 검색 결과에 없는 경우 직접 입력 옵션 제공
- 입력 필드: 제목 (필수), 저자 (선택), 표지 이미지 URL (선택)

#### 2.1.3 도서 추가 시 함께 입력 가능한 항목
- 독서 상태 지정 (선택)
- 카테고리 지정 (선택, 다중)
- 메모/노트 (선택)

---

### 2.2 독서 상태 관리

#### 2.2.1 사용자 정의 상태
- 사용자가 상태 레이블을 자유롭게 생성 가능
- 기본 예시 (변경/삭제 가능): 읽고 싶음, 읽는 중, 완독, 중단
- 상태에 색상 부여 가능 (선택)

#### 2.2.2 상태 CRUD
- 상태 생성 / 이름 수정 / 삭제
- 상태 삭제 시, 해당 상태가 지정된 도서에서 상태가 제거됨 (경고 표시)

#### 2.2.3 도서에 상태 지정
- 도서 1권에 상태 1개만 지정 가능
- 상태 미지정 허용

---

### 2.3 카테고리 관리

#### 2.3.1 사용자 정의 카테고리
- 사용자가 카테고리 이름을 자유롭게 생성 가능
- 예시: 소설, 자기계발, 추천도서, 재독하고 싶음 등
- 카테고리에 색상 부여 가능 (선택)

#### 2.3.2 카테고리 CRUD
- 카테고리 생성 / 이름 수정 / 삭제
- 카테고리 삭제 시, 해당 카테고리가 지정된 도서에서 카테고리가 제거됨 (경고 표시)

#### 2.3.3 도서에 카테고리 지정
- 도서 1권에 여러 카테고리 동시 지정 가능 (다중 선택)
- 카테고리 미지정 허용

---

### 2.4 독서 메모/노트

- 도서별 자유형식 텍스트 메모 작성
- 완독 여부와 무관하게 언제든 작성/수정 가능
- 길이 제한 없음

---

### 2.5 도서 목록

#### 2.5.1 목록 보기
- 전체 도서 목록을 카드 형태로 표시
- 카드에 표시되는 정보: 표지 이미지, 제목, 저자, 독서 상태, 카테고리 태그

#### 2.5.2 도서 수정 / 삭제
- 도서 정보 (제목, 저자, 표지, 메모, 상태, 카테고리) 수정 가능
- 도서 삭제 (확인 다이얼로그 표시)

---

### 2.6 데이터 내보내기/가져오기

#### 2.6.1 내보내기 (Export)
- 전체 도서 목록을 JSON 파일로 다운로드
- 카테고리, 상태 정보 포함

#### 2.6.2 가져오기 (Import)
- JSON 파일 업로드로 도서 데이터 복원
- 중복 도서 처리 방식: 기존 데이터 유지 (덮어쓰지 않음)

---

### 2.7 검색 및 필터링

#### 2.6.1 검색
- 내 도서 목록에서 제목 또는 저자명으로 검색

#### 2.6.2 필터링
- 카테고리별 필터 (다중 선택 가능)
- 독서 상태별 필터
- 필터 초기화 버튼

---

## 3. 데이터 모델

### Book
| 필드 | 타입 | 설명 |
|------|------|------|
| id | string (UUID) | 고유 식별자 |
| title | string | 제목 (필수) |
| author | string | 저자 |
| cover_image_url | string | 표지 이미지 URL |
| status_id | string \| null | 독서 상태 ID |
| category_ids | string[] | 카테고리 ID 목록 |
| note | string | 독서 메모 |
| pos_x | float \| null | 자유 배치 X 좌표 |
| pos_y | float \| null | 자유 배치 Y 좌표 |
| created_at | datetime | 생성일시 |
| updated_at | datetime | 수정일시 |

### Status (사용자 정의 독서 상태)
| 필드 | 타입 | 설명 |
|------|------|------|
| id | string (UUID) | 고유 식별자 |
| name | string | 상태 이름 (예: 읽는 중) |
| color | string | 색상 코드 (선택) |

### Category (사용자 정의 카테고리)
| 필드 | 타입 | 설명 |
|------|------|------|
| id | string (UUID) | 고유 식별자 |
| name | string | 카테고리 이름 |
| color | string | 색상 코드 (선택) |

## 4. 기술 스택

| 영역 | 기술 |
|------|------|
| Frontend + Backend | Next.js (App Router) |
| 데이터베이스 | Supabase (PostgreSQL) |
| 인증 | Supabase Auth |
| 스타일링 | Tailwind CSS |
| 외부 API | Google Books API (무료, API 키 필요) |

---

## 5. 비기능 요구사항

- **인증**: Supabase Auth를 통한 로그인 (단일 사용자 개인앱, 회원가입 불필요)
- **반응형 UI**: 모바일 브라우저에서도 사용 가능
- **서버 사이드 렌더링**: Next.js Server Components 활용, 초기 로딩 성능 확보
